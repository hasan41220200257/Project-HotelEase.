# Project-HotelEase.
Project Title : HotelEase 
. Created by Natasha Roy Katha (41240202386), Mahedi Hasan (41220200257)

A robust Hotel Management System developed in C, featuring guest check-in/check-out, room reservation management, and automated billing modules using file handling for data persistence.

This is a CLI (Command Line Interface) application designed to streamline hotel operations. It focuses on memory efficiency and structured programming in C.

Key Features:

Room Management: Add, delete, and modify room categories and availability.

Customer Records: Store guest details, stay duration, and ID verification.

Billing System: Calculate total costs including room service and taxes.

Data Persistence: Uses File I/O to ensure data is saved even after the program closes.

Search Functionality: Quickly find guest records by room number or name.

Guests review.

How to run it : it can be run with any compiler that can run program using c language. like codeblocks.
